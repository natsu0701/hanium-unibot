# school_id 필터링 검증 리포트

---

## 실험 목적

> **더미데이터를 이용한 확장성 검증**
> 
- 특정 학교로 필터링하면 그 학교 데이터만 나온다 (새지 않는다)
- 필터 없이 검색하면 여러 학교가 다 후보에 오른다 (관리자 모드 정상)
- 서로 다른 학교로 필터링한 결과는 항상 서로 다르다 (필터가 실제로 구분해서 작동한다)

---

## 실험 환경

- **실험 스크립트**: `backend/experiments/school_scope_eval.py`
- **임베딩 모델**: jhgan/ko-sroberta-multitask
- **테스트 질문**: "휴학 신청 방법"
- **컬렉션 구성**: konkuk(실증 데이터) + demo_univ_1/2/3(dummy 학교, 각 konkuk 데이터에서 25개 청크 랜덤 샘플링)
- **min_score**: 0.0 (임계값 없이 전체 결과 확인 목적. 실제 서비스는 min_score=0.20 적용됨)
---

## 실험 결과

### 1. 학교별 문서 수 (list_schools, distinct doc_id 기준)

| school_id | 문서 수 |
| --- | --- |
| konkuk | 4 |
| demo_univ_1 | 4 |
| demo_univ_2 | 4 |
| demo_univ_3 | 4 |

**참고 이슈**: konkuk 문서 수는 건국대 학사요람 PDF 용량이 커서 4분할하여 파싱했기 때문에 4개로 집계됨. (분할본마다 별도 doc_id 부여됨). 실제 원본 문서는 1개(학칙)이며, doc_count는 "분할 파싱 단위" 기준으로 집계되는 것이 현재 구조의 특성.

### 2. school_id='konkuk' 필터링 검색 검증

| score | school_id |
| --- | --- |
| 0.4627 | konkuk |
| 0.4161 | konkuk |
| 0.3211 | konkuk |
| 0.3112 | konkuk |
| 0.3023 | konkuk |

**결과: konkuk 이외 school_id 섞임 0건 → 필터링 정상 동작 ✅**

동일 질문에 대해 `where={"school_id": "konkuk"}` 필터를 걸었을 때, 다른 학교(demo_univ_1/2/3) 데이터가 전혀 섞이지 않고 konkuk 데이터만 검색됨을 확인.

**참고 이슈**: 모든 결과의 `article_title`이 빈 문자열(`''`)로 나옴 — school_id 필터링과는 무관한 별도 이슈로, PDF 원문에서 조 번호/제목 패턴이 정규식/파싱 규칙과 맞지 않아 발생하는 것으로 추정. 별도 확인 필요.

### 3. school_id 필터 없이 검색 (관리자 모드)

**결과에 섞인 school_id 종류: `['demo_univ_2', 'konkuk']`**

필터 없이 검색 시 2개 이상의 학교가 후보로 등장 → 필터를 걸지 않으면 여러 학교 데이터가 섞여 나온다는 것을 확인, 즉 **school_id 필터의 필요성이 실증됨 ✅**

### 4. 스코프별 비교 (konkuk vs demo_univ_1 vs 전체)

| 스코프 | 결과 수 | Top-1 |
| --- | --- | --- |
| konkuk | 5건 | "휴학 만료된 자가 소정의 기일 내에 원학년에 정상 복학하는 경우" |
| demo_univ_1 | 5건 | "다) 수강신청(개설정보/과목번호 입력) 및 삭제" |
| 전체(필터 없음) | 5건 | "휴학 만료된 자가 소정의 기일 내에 원학년에 정상 복학하는 경우" |

- **서로 다른 school_id로 필터링한 결과가 항상 다름 → True ✅**
(konkuk과 demo_univ_1의 결과가 완전히 다른 문서/조/페이지 조합으로 확인됨)
- **참고**: '전체(필터 없음)' 결과가 'konkuk' 결과와 동일 — konkuk 데이터가 해당 질문에서 상위 점수를 독점하고 있기 때문으로, 필터링 실패가 아닌 데이터 편중에 따른 정상 현상.

## 결론

**✅** 특정 school_id로 필터링 시 타 학교 데이터 섞임 없음

**✅** 필터 없을 시 여러 학교가 후보로 등장 (필터 필요성 실증)

**✅** 서로 다른 school_id 필터링 결과가 서로 다름

**→ school_id 기반 다중 학교 검색 필터링 아키텍처가 의도대로 동작함을 확인.**

### 추후 확인 필요 사항

1. konkuk doc_count=4 집계 이슈 — 학사요람 PDF를 4분할하여 파싱한 결과, 분할본마다 별도 doc_id가 생성되어 실제 문서 1개가 "4개"로 집계됨. (해결된 이슈는 아니고, doc_count의 의미를 "원본 문서 수"가 아닌 "분할 파싱 단위 수"로 해석해야 한다는 점을 계속 유의해야 함.)
2. article_title 빈 값 이슈 — json 파일 확인 결과, chapter, chapter_title, article, article_title이 제대로 나오지 않음. `제(\d+)조` 같은 정규식의 문제로 추정. — 검증 필요.
